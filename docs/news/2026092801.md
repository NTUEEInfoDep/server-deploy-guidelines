# 網站服務部署規範上線公告

資訊部的網站服務申請與部署規範已經上線。這份規範整理了使用 `ntuee.org` Domain，以及將服務部署到資訊部伺服器時的申請方式與技術要求，內容包含 Domain 與 Service ID 命名、Repository 準備、Docker Compose 設定、資料保存、部署文件及上線前檢查。

為配合新規範實施，原先運行於資訊部伺服器上的既有服務目前皆已停止。請各單位負責人依照以下流程重新申請及上線：

1. 閱讀[網站服務申請與部署](../server/application.md)、[部署規範](../server/deployment.md)及[Docker 部署規範](../server/docker.md)。
2. 依規範修改服務的 Repository，補齊 Production 部署設定與部署說明。
3. 參照[部署檢查清單](../server/checklist.md)完成檢查後，填寫[網站服務申請表](https://forms.gle/v27p3Fip8TT9CtUL6)。
4. 待資訊部確認 Domain、Service ID 與部署設定後，再將服務重新上線。

請勿直接重啟原有服務。若服務有特殊的 network、權限、Host Port 或 Nginx 設定需求，請在申請時一併說明。
